# MacDiskTemp

물리 디스크를 선택해서 온도와 SMART 상태를 확인하는 macOS 네이티브 앱입니다. SwiftUI로 작성했으며, Homebrew에 설치된 `smartctl`을 사용합니다.

## 사용하기

소스를 내려받았다면 **먼저 빌드한 뒤 실행**합니다. 다운로드하거나 복제한 폴더의 상위 디렉터리에서:

```sh
cd MacDiskTemp-Public
bash Scripts/build-app.sh
open dist/MacDiskTemp.app
```

완성된 **DMG 배포 파일을 받았다면 빌드할 필요가 없습니다.** DMG를 열고 `MacDiskTemp.app`을 `Applications`로 끌어다 놓은 뒤 응용 프로그램 폴더에서 실행하세요. ZIP 배포 파일도 압축을 풀고 앱을 옮겨 실행하면 됩니다. 소스 코드 ZIP에는 완성된 앱이 포함되지 않습니다. 배포 파일은 Mac의 CPU 종류(Apple Silicon: `arm64`, Intel: `x86_64`)에 맞게 선택하세요.

1. 빌드한 앱 또는 응용 프로그램 폴더에 복사한 `MacDiskTemp.app`을 실행합니다.
2. 도구가 없으면 첫 실행에 **자동 설치** 화면이 열립니다. **자동 설치 시작**을 누르면 Homebrew → smartmontools 순으로 없는 도구를 설치하고 측정을 시작합니다. 왼쪽 목록에서 내장 또는 외장 디스크를 선택합니다.
3. 기본 화면은 **가로 3칸·세로 2칸**입니다. 첫째 줄은 현재·최고·평균 온도, 둘째 줄은 남은 수명·저장 공간 사용률·누적 읽기/쓰기입니다.
4. **최고 온도** 카드에 마우스를 올리면 SMART의 경고·위험 온도 유지 시간과 온도 기준값을 볼 수 있습니다.
5. **더보기**를 누르면 나머지 SMART 데이터가 펼쳐집니다. **장치 정보**에서 모델·일련번호·펌웨어를, **SMART 원문**에서 텍스트 또는 JSON을 확인하고 복사합니다.
6. 상단에서 자동 갱신을 끄거나 15초·30초·1분·5분으로 설정합니다. 기본값은 30초입니다. `⌘R`로 즉시 새로고침할 수 있습니다.

앱은 실행 중에도 Dock과 `⌘Tab` 앱 전환 목록에 표시되지 않습니다. 창을 닫아도 메뉴 막대에 선택한 디스크의 온도가 표시됩니다. 메뉴 막대에서 디스크를 바꾸거나 **대시보드 열기**로 창을 다시 열 수 있습니다. 완전히 종료하려면 메뉴의 **MacDiskTemp 종료**를 사용합니다.

최고·평균 온도는 **이번 앱 실행 중에 성공한 측정값만** 디스크별로 누적합니다. 평균은 측정값의 산술 평균입니다. 디스크를 전환해도 같은 실행 중의 기록은 남으며, 앱을 완전히 종료하고 다시 실행하면 초기화됩니다. 창만 닫으면 메뉴 막대에서 계속 측정합니다.

‘누적 측정 시간’은 선택한 디스크를 자동 갱신으로 연속 측정한 구간의 합입니다. 디스크 전환, 조회 실패, 긴 측정 공백 및 자동 갱신이 꺼진 기간을 포함하지 않습니다. 최고 온도의 툴팁에 나오는 경고·위험 온도 유지 시간은 **디스크 자체가 SMART에 기록한 전체 사용 기간의 값**이며 앱의 누적 측정 시간과 다릅니다.

## 요구 사항

- macOS 13 이상
- `smartmontools` 7 이상 (`smartctl` JSON 지원 필요)
- Apple Silicon 또는 Intel Mac. 빌드 스크립트는 빌드를 실행한 Mac의 아키텍처로 앱을 만듭니다.

앱은 Apple Silicon의 `/opt/homebrew/bin/smartctl`과 Intel의 `/usr/local/bin/smartctl`을 비롯한 일반 설치 경로를 자동으로 찾습니다. 다른 위치에 설치했다면 앱 **설정**에서 실행 파일을 선택하세요.

### 첫 실행 자동 설치

- `smartctl`이 있으면 바로 측정합니다. 없으면 설치 화면을 자동으로 표시합니다.
- **자동 설치 시작**을 누르면 macOS 터미널이 열려 명령을 자동 실행합니다. Homebrew가 있으면 smartmontools만 설치합니다.
- Homebrew가 없으면 [공식 설치 스크립트](https://github.com/Homebrew/install)를 내려받아 실행합니다. 최초 한 번 관리자 비밀번호와 Return 키 확인이 필요할 수 있습니다. 비밀번호는 터미널에서 입력하며 앱이 수집·저장하지 않습니다.
- Apple Command Line Tools가 필요한 환경에서는 Homebrew 설치기가 해당 설치를 진행합니다. 인터넷 연결과 충분한 시간이 필요합니다. 설치 진행 상태는 앱에서도 표시합니다.
- 설치가 끝나면 도구 실행을 확인하고 자동으로 측정합니다. 실패·중단 시 원인을 터미널에서 확인하고 앱에서 다시 시도할 수 있습니다. 중단은 터미널에서 Control+C를 누릅니다. 앱 종료만으로 설치가 중단되지는 않습니다.
- 현재 Homebrew의 공식 지원 환경은 Apple Silicon / macOS 15 이상입니다. Intel 및 이전 macOS는 지원이 제한됩니다. 앱 자체의 최소 버전과 Homebrew의 지원 범위는 다릅니다. 최신 기준: [Homebrew 설치 요구 사항](https://docs.brew.sh/Installation).

설치는 Homebrew와 smartmontools를 Mac에 추가합니다. 앱을 지워도 이 도구들은 남습니다. 스마트 디스크 조회 자체에는 인터넷이 필요하지 않습니다.

## 빌드 및 개발

직접 빌드하려면 Xcode 16 이상 또는 Swift 6 이상이 필요합니다. 외부 Swift 패키지 의존성은 없습니다. 프로젝트 폴더 안에서 실행합니다.

```sh
bash Scripts/build-app.sh
open dist/MacDiskTemp.app
```

Xcode에서는 `Package.swift`를 열면 됩니다. 위 스크립트는 `dist/MacDiskTemp.app`, 버전·CPU 종류를 표시한 ZIP과 DMG, `SHA256SUMS.txt`를 만듭니다. 빌드 결과는 로컬 실행용 임시 서명(ad-hoc)이며 Developer ID 서명·공증은 아직 적용하지 않았습니다. DMG 포장만으로 이 제한이 없어지지는 않습니다. 다른 Mac에서 다운로드해 실행하면 macOS가 차단할 수 있습니다. 신뢰하는 배포본에 한해 시스템 설정의 개인정보 보호 및 보안에서 실행을 허용해야 할 수 있습니다.

공개 저장소에는 생성된 앱·ZIP·DMG·Finder 메타데이터·개인 Xcode 상태를 커밋하지 않습니다. 완성된 배포 파일은 소스와 별도로 공유하며, 빌드만으로 GitHub Release에 업로드되지는 않습니다. 개인정보 점검은 [PRIVACY.md](PRIVACY.md)를 참고하세요.

```sh
swift test
swift run diskprobe
```

`diskprobe`는 앱과 같은 조회 모듈로 연결된 물리 디스크를 검사하는 개발용 도구입니다. 일련번호나 전체 SMART 보고서를 파일에 저장하지 않습니다.

## 데이터 처리

- `diskutil list -plist physical`: 물리 디스크만 나열합니다. APFS 합성 디스크·파티션·디스크 이미지는 별도 선택 항목으로 표시하지 않습니다.
- `diskutil info -plist /dev/diskN`: 장치 이름·용량·내장 여부·연결 방식을 읽습니다. `OSInternal`이 아니라 `Internal` 필드로 내장 여부를 구분합니다.
- `smartctl -a --json=ov /dev/diskN`: SMART 데이터와 텍스트 원문을 한 번에 읽습니다.
- `diskutil apfs list -plist`: 선택한 물리 디스크의 APFS 컨테이너 전체 용량에서 여유 공간을 뺀 값을 사용량으로 표시합니다. 공유 볼륨·스냅샷 공간은 컨테이너별로 한 번만 계산하며, 다른 디스크 및 디스크 이미지는 제외합니다. APFS가 아닌 디스크는 마운트된 일반 볼륨의 파일시스템 사용량을 합산합니다.
- 저장 공간 카드의 툴팁에 계산 범위와 남은 용량을 표시합니다. APFS와 다른 파일시스템이 섞인 디스크에서는 APFS 컨테이너 범위를 사용합니다. EFI·미할당 공간은 제외하며, 여러 물리 디스크에 걸친 컨테이너는 디스크별 사용량을 추정하지 않습니다.
- NVMe 누적 읽기/쓰기는 데이터 단위당 **512,000바이트**로 계산하고 십진 단위로 표시합니다.
- ATA는 공통 온도·상태·사용 시간과 제조사별 SMART 원시 속성을 표시합니다. 단위가 제조사에 따라 달라지는 ATA 속성을 임의로 TB나 수명 백분율로 변환하지 않습니다.
- 미제공 항목은 `—`로 표시합니다. 수명 사용률은 저장 공간 사용률이 아니며 100%를 넘을 수 있습니다.
- 기본 화면의 남은 수명은 `max(0, 100 - 수명 사용률)%`입니다. 제조사 추정치이며, 원래의 수명 사용률도 같은 카드에 함께 표시합니다.
- 온도 경고·위험 기준은 장치가 보고한 값만 사용합니다.
- SMART 종료 코드는 비트 마스크로 처리합니다. 디스크 건강 경고와 명령 실행 실패를 구분하고, 부분 응답은 주의 문구와 함께 표시합니다.
- 갱신 실패 시 이전 값임을 표시하며 메뉴 막대 온도는 숨깁니다. 디스크 선택 시 이전 장치의 측정값을 지웁니다.
- 디스크 조회 명령은 UI와 별도로 실행하고 10~20초 시간 제한을 둡니다. 셸을 거치지 않고 인자를 직접 전달합니다. 최초 도구 설치는 별도 터미널 스크립트로 실행합니다.
- 측정 데이터는 메모리에만 유지합니다. 설정과 마지막 선택한 디스크 경로만 사용자 설정에 저장합니다.

APFS 공유 공간 기준: [Apple의 APFS 공간 공유 설명](https://support.apple.com/en-asia/guide/mac-help/sysp560a2952/mac).

명령 옵션과 종료 상태 기준: [smartmontools 공식 smartctl 매뉴얼](https://github.com/smartmontools/smartmontools/blob/main/src/smartctl.8.in).

## 지원 범위와 제한

- USB 케이스·브리지·장치에 따라 macOS에서 SMART 정보를 전달하지 못할 수 있습니다. 이때 앱에 상세 오류를 표시합니다. macOS용 smartctl이 지원하지 않는 브리지를 앱이 대신 지원하지는 않습니다.
- 관리자 권한이 필요한 장치는 원인을 안내합니다. 첫 버전은 관리자 권한 서비스나 비밀번호 수집 기능을 포함하지 않습니다.
- 디스크 연결 변경은 새로고침할 때 반영됩니다. 선택한 디스크가 없어지면 남아 있는 외장 디스크, 그다음 첫 디스크 순으로 선택합니다.
- 자동 갱신은 선택한 디스크만 측정합니다. HDD 등은 조회 시 절전 상태에서 깨어날 수 있으므로 필요에 따라 간격을 늘리거나 자동 갱신을 끌 수 있습니다.
- 누적 온도 그래프, 시작 시 자동 실행, 알림, App Store 배포는 후속 기능입니다.
